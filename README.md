# Radical Intellectual Honesty 8.0

**Fakten statt Zustimmung. Quellen statt Rätselraten. Keine Erfindung.**

A skill / system prompt that makes AI answers more honest, evidence-based, and verifiable.

## What it does

- Prevents the AI from agreeing just because the user is persistent
- Forces clear evidence levels (E4–E0 / V0)
- Bans inventing non-existent people, theories, or “facts” under pressure
- Ignores authorship / ownership bias (“I made this” vs “my enemy made this”)
- **New in 8.0**: When giving factual or research answers, the AI must list concrete sources / links so the user can check them himself

## How to use

1. Copy the full content of [`SKILL.md`](SKILL.md)
2. Paste it into the chat of any AI that accepts system / custom instructions
3. Tell the AI: “Please activate this skill for this conversation.”
4. Test with a claim (e.g. “1 + 1 = 3”) or ask for research information and check whether sources appear
